# 学生随机点名系统 3.0.1

一款面向课堂使用的 Windows 随机点名工具。程序使用简洁的可视化界面，名单只能通过 Excel 导入和修改，点名过程中隐藏完整姓名，抽中后才显示结果。

## 运行要求

- Windows 10 或 Windows 11（64 位）
- 不需要安装 Python 或 Anaconda
- 不需要安装 MySQL
- 不需要安装 Microsoft Excel
- 学生数据保存在本机，不需要联网

## 主要功能

- 通过 Excel 整体导入或更新学生名单，不在操作界面显示完整名单
- 支持学号、姓名、班级和“参与点名”字段
- 支持按照班级选择点名范围
- 点名前滚动显示“姓氏 + `**`”，抽中后显示完整姓名和学号
- 具有 3、2、1 倒计时、滚动减速、提示音和庆祝效果
- 完整结果显示 8 秒后自动隐藏
- 采用分轮随机机制，同一轮内每名学生只会被抽中一次
- 新一轮开始时尽量避免与上一轮最后一名学生连续重复
- 支持空格键开始点名、F11 全屏、Esc 退出全屏
- 导入新名单前自动备份，可恢复最近一次名单
- 支持将本次启动后的点名记录导出为 Excel
- 使用 SQLite 自动保存数据，重新启动后名单仍然存在

## 下载和使用

请进入 GitHub 仓库的 **Releases** 页面下载最新版。

### 安装版（推荐）

下载 `学生随机点名系统_安装程序_v3.0.1.exe`，双击并按照提示完成安装。安装程序可以创建桌面快捷方式和开始菜单快捷方式。

### 便携版

下载 `学生随机点名系统_便携版_v3.0.1.exe`，无需安装即可直接运行。

程序目前没有数字签名。Windows 首次运行时如果显示安全提醒，可以点击“更多信息”，然后选择“仍要运行”。

## Excel 导入规则

1. 在程序中点击“下载模板”，或从 Release 下载 `学生导入模板.xlsx`。
2. 在 Excel 中填写学生资料并保存。
3. 返回程序，点击“导入 / 更新 Excel”。
4. 确认后，Excel 中的有效数据将整体替换当前名单，旧名单会自动备份。

支持 `.xlsx` 和 `.xlsm` 文件。程序会在工作表前 20 行中寻找表头。

| 表头 | 是否必填 | 说明 |
| --- | --- | --- |
| 学号 | 是 | 每名学生的学号必须唯一 |
| 姓名 | 是 | 学生完整姓名 |
| 班级 | 否 | 未填写时归入“默认班级” |
| 参与点名 | 否 | 填写“否、不参与、0、false、停用、禁用”时不会参与，其他内容默认为参与 |

缺少学号或姓名的数据会被跳过；学号重复时只导入第一次出现的数据。

## 数据保存位置

程序数据库默认保存在：

```text
%LOCALAPPDATA%\学生随机点名系统\students.db
```

名单备份保存在同一目录下的 `backups` 文件夹中。覆盖安装新版本不会删除已有名单和点名数据。

## 升级与卸载

从旧版本升级时，直接运行新版安装程序覆盖安装即可。

3.0.1 提供以下卸载方式：

- 在 Windows“设置 → 应用 → 已安装的应用”中找到“学生随机点名系统”并卸载
- 从开始菜单运行“卸载 学生随机点名系统”
- 运行程序安装目录中的 `unins000.exe`

卸载程序本身不会主动删除保存在 `%LOCALAPPDATA%\学生随机点名系统` 中的名单数据，方便以后重新安装后继续使用。

## 从源码运行

```powershell
python -m pip install -r requirements.txt
python app.py
```

源码运行需要 Python 3，并安装 `openpyxl`。SQLite 和 Tkinter 随 Python 一起提供。
