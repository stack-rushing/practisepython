# 学生随机点名系统 2.1

这是一个无需 MySQL 的 Windows 桌面应用。

## 主要功能

- SQLite 本地保存学生名单
- 学生名单完全隐藏，不在界面中显示
- 只能通过 Excel 统一导入或替换名单
- 点名时快速滚动“张**”等遮罩姓名并逐渐减速
- 停止后才显示完整姓名和学号
- 可避免连续抽中同一名学生
- 自动保存，重新启动后数据仍然存在

## Excel 导入规则

- 支持 `.xlsx` 和 `.xlsm`
- 工作表前 20 行中需要同时包含“学号”和“姓名”表头
- 学号必须唯一
- 缺少学号或姓名的行会被跳过
- 建议使用程序内的“保存导入模板”按钮获取标准模板

## 数据位置

数据库默认保存在：

`%LOCALAPPDATA%\学生随机点名系统\students.db`

目标电脑不需要安装 Python、Anaconda、MySQL 或 Excel。
