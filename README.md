# 学生随机点名系统 3.0

这是一个无需 MySQL 的 Windows 桌面应用。

## 主要功能

- SQLite 本地保存学生名单
- 极简隐藏名单界面，名单只能通过 Excel 修改
- 支持班级和“参与点名”字段
- 每轮每名学生只出现一次，全班点完后开始下一轮
- 3、2、1 倒计时、音效、遮罩滚动、减速停靠和揭晓动画
- 完整姓名显示 8 秒后自动隐藏
- 空格键点名，F11 全屏，Esc 退出全屏
- 导入前自动备份，可恢复上次名单
- 支持导出本次启动后的点名记录
- 自动保存，重新启动后数据仍然存在

## Excel 导入规则

- 支持 `.xlsx` 和 `.xlsm`
- 工作表前 20 行中需要同时包含“学号”和“姓名”表头
- 推荐同时包含“班级”和“参与点名”两列
- 学号必须唯一
- 缺少学号或姓名的行会被跳过
- 建议使用程序内的“保存导入模板”按钮获取标准模板

## 数据位置

数据库默认保存在：

`%LOCALAPPDATA%\学生随机点名系统\students.db`

目标电脑不需要安装 Python、Anaconda、MySQL 或 Excel。
